## 💡 Sequential Execution Rationale

Due to CPU-throttling inside virtualized macOS container runtimes (such as Podman/Docker on Mac), parallel worker threads can trigger timeout failures on handshakes. To guarantee maximum stability and speed, tests are run sequentially:

```bash
npx vitest run --pool=forks --maxWorkers=1 --minWorkers=1 --test-timeout=30000
```
This executed 78 integration tests in **under 25 seconds** with 100% success rate!
