# Data Model — Developer Documentation Site

## Entities

### Site (docusaurus.config.ts)

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `title` | string | yes | "Agnostic Cloud" |
| `tagline` | string | yes | "Unified cloud abstraction layer for AWS, GCP, and Azure" |
| `url` | string | yes | `https://agnostic-cloud.github.io` |
| `baseUrl` | string | yes | `/agnostic-layer/` |
| `organizationName` | string | yes | `agnostic-cloud` |
| `projectName` | string | yes | `agnostic-layer` |
| `deploymentBranch` | string | yes | `gh-pages` |
| `favicon` | string | yes | `img/favicon.ico` |
| `presets` | Preset[] | yes | `@docusaurus/preset-classic` |
| `plugins` | Plugin[] | yes | typedoc, mermaid |
| `themeConfig` | object | yes | navbar, footer, algolia, mermaid, prism |

### Sidebar

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `items` | SidebarItem[] | yes | Array of doc categories, refs, or links |
| `label` | string | yes | Display name in sidebar |
| `type` | `'doc' \| 'category' \| 'link'` | yes | Sidebar item type |

**Sidebar Hierarchy**:
```
Home                    → docs/index.md
Quickstart              → docs/quickstart.md
Packages                → category
  @agnostic-cloud/*     → doc (auto-generated by TypeDoc)
Guides                  → category
  Cross-Cloud Migration → docs/guides/cross-cloud-migration.md
  Local Emulators       → docs/guides/local-emulators.md
  Multi-Service Patterns→ docs/guides/multi-service-patterns.md
Reference               → category
  LLM Reference         → docs/llm-reference.md
  Error Reference       → docs/errors.md
```

### Page

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | yes | Unique identifier matching file path |
| `title` | string | yes | Frontmatter title |
| `sidebar_label` | string | no | Custom label in sidebar |
| `slug` | string | no | Custom URL slug |
| `description` | string | no | Meta description for SEO |
| `content` | MDX | yes | Body content |
| `tags` | string[] | no | Frontmatter tags for filtering |
| `draft` | boolean | no | Hide from production build |
| `version` | string | no | Docusaurus version label |

### Package (one of 7 @agnostic-cloud/*)

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `npmName` | string | yes | e.g., `@agnostic-cloud/storage` |
| `displayName` | string | yes | e.g., "Storage" |
| `description` | string | yes | Package description from package.json |
| `supportedClouds` | Cloud[] | yes | `['aws', 'gcp', 'azure']` or subset |
| `factoryFunction` | string | yes | e.g., `createStorage(config)` |
| `strategyInterface` | string | yes | e.g., `StorageStrategy` |
| `configType` | string | yes | e.g., `StorageConfig` |
| `entryPoint` | string | yes | Path to `src/index.ts` |
| `errors` | Error[] | yes | Package-specific error types |

**Package instances**:
| Package | Clouds | Factory | Interface |
|---------|--------|---------|-----------|
| `@agnostic-cloud/storage` | aws, gcp, azure | `createStorage()` | `StorageStrategy` |
| `@agnostic-cloud/secrets` | aws, gcp, azure | `createSecrets()` | `SecretsStrategy` |
| `@agnostic-cloud/cache` | aws, gcp, azure | `createCache()` | `CacheStrategy` |
| `@agnostic-cloud/kms` | aws, gcp, azure | `createKms()` | `KmsStrategy` |
| `@agnostic-cloud/pubsub` | aws, gcp, azure | `createPubSub()` | `PubSubStrategy` |
| `@agnostic-cloud/nosql` | aws, gcp, azure | `createNoSql()` | `NoSqlStrategy` |
| `@agnostic-cloud/migrate` | aws, gcp, azure | `copyObject()` / `verifyIntegrity()` | (functions) |

### Cloud Provider

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | `'aws' \| 'gcp' \| 'azure'` | yes | Provider identifier |
| `displayName` | string | yes | "AWS" / "GCP" / "Azure" |
| `color` | string | no | Brand color for UI |
| `emulatorPort` | number | no | Local emulator port |

### Guide

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | yes | URL-friendly identifier |
| `title` | string | yes | Display title |
| `category` | `'migration' \| 'local-dev' \| 'patterns'` | yes | Guide category |
| `prerequisites` | string[] | no | Required packages or setup |

### API Reference

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `packageId` | string | yes | Links to Package entity |
| `sourceFile` | string | yes | Path to `src/index.ts` |
| `generatedPath` | string | yes | Output path under `docs/api/` |
| `typeDocConfig` | object | yes | TypeDoc options per entry |
| `generatedTypes` | TypeEntity[] | yes | All exported types from the entry point |

## Relationships

```
Site 1──N Sidebar
Site 1──N Page
Site 1──1 Package[]
Site 1──1 Guide[]
Site 1──1 CloudProvider[]

Page N──1 Package    (API reference pages belong to a package)
Page N──1 Guide      (guide pages)
Page N──N CloudProvider  (examples may cover multiple clouds)

Package N──N CloudProvider  (each package supports 1-3 clouds)
Package 1──N ErrorType      (each package has its own errors)

APIReference 1──1 Package   (generated from source)
APIReference N──N TypeEntity (generated types)
```

## State Transitions

### Page Lifecycle
```
Draft → Published → Versioned (snapshot) → Archived
```

### Documentation Version Lifecycle
```
0.1.0 (current/next) → 0.1.0 (frozen on release) → next (0.2.0-dev)
```
