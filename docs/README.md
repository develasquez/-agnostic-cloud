# Documentation Site

Docusaurus documentation for the Agnostic Cloud monorepo.

## Prerequisites

- Node.js >= 20
- Packages must be built before running docs (TypeDoc reads built output)

## Local Development

```bash
# From repo root: build all packages first
npm run build -w packages

# From docs/ directory
npm install
npm start
```

This starts the dev server at `http://localhost:3000/-agnostic-cloud/`.

## Build

```bash
npm run build
```

Output goes to `build/`.

## Project Structure

```
docs/
├── docs/              ← Documentation content (Markdown/MDX)
│   ├── index.md       ← Docs home
│   ├── quickstart.md
│   ├── packages/      ← Per-package overview pages
│   ├── guides/        ← Usage guides
│   ├── llm-reference.md
│   ├── errors.md
│   └── api/           ← Auto-generated by TypeDoc
├── src/
│   ├── components/    ← React components (CloudTabs, PackageGrid, ArchitectureDiagram)
│   └── css/           ← Custom styles
├── static/            ← Images, favicon
├── sidebars.ts
├── docusaurus.config.ts
└── package.json       ← Separate from monorepo workspace
```

## Versioning

- `current` tracks `main` (published at `/docs/next/`)
- Run `npm run docusaurus docs:version 0.1.0` to freeze a release
